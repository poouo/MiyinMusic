觅音 Windows 原生客户端 v1.0.0
===============================

免安装版本：解压后直接运行 MiYin.exe。

系统要求
- Windows 10 1809+ 或 Windows 11，x64
- 需要可用的音频输出设备；没有音频设备时会自动进入静音播放，进度和歌词仍会推进
- 不需要安装 .NET / Windows App SDK（已自包含）

默认服务器
- 客户端固定连接 https://music.poouo.com，不提供服务器配置入口
- 启动后直接进入主界面，连接过程在后台完成；断网时先展示上次缓存的首页内容
- 不显示“已连接”状态，连接成功后会静默刷新内容

托盘
- 关闭窗口默认隐藏到托盘，不会直接退出；托盘右键菜单可“退出”
- 最小化默认保持任务栏按钮，可在“设置 → 窗口与托盘”中开启“最小化时隐藏到托盘”
- 左键托盘图标恢复窗口；如果托盘图标被 Windows 折叠，请点任务栏的 ^ 展开
- 也可以在设置里关闭“关闭窗口时隐藏到托盘”

数据位置
- 配置：%APPDATA%\MiYin\config.json
- 自动缓存：%LOCALAPPDATA%\MiYin\Cache
- 主动下载：%USERPROFILE%\Music\觅音

功能
- 发现、排行榜、歌单广场、搜索、歌单/歌手详情
- 我的喜欢、最近播放、自建歌单、播放队列
- 逐行歌词、全屏播放、音质切换、下载管理、本地缓存设置
- 账号登录/注册与收藏、歌单、记录同步
- 系统托盘、关闭/最小化到托盘
- 无音频设备时静音播放

说明
- 音源脚本由服务端自动更新，客户端无需配置音源
- 主动下载永久保留，不计入缓存上限；自动缓存按最久未播放清理
