## 入口与行为

### 1. 搜索与列表

- Web 搜索以路由作为常规请求触发源，一次提交只发起一次请求。慢旧请求不会覆盖新关键词或平台；翻页失败保留已加载结果。
- Android 搜索取消上一任务并核对请求版本，展示总数和加载更多入口。
- Windows 搜索不再因旧请求正在执行而丢弃新请求，成功后才提交页码。歌曲列表使用有界 ListView；已有前缀保持一致时只追加新行，元数据变化时刷新。
- Windows 2000 首场景的帧率、内存与持续滚动尚未实测，没有量化性能提升数据。

### 2. Android 歌单及队列

- “我的”提供新建和歌单管理；歌曲更多菜单提供加入歌单、移出当前歌单、上下移动、下一首播放和加入队列。
- 播放队列提供上移、下移、移除和清空。删除当前歌曲会切换实际音源，并保留原播放或暂停意图。
- 库变更复用服务端接口，更新当前账号音乐库；其他设备下次刷新后可见，未新增实时推送同步。

### 3. 听歌设置与恢复

- Web：完整播放页顶部“听歌设置”。Android：播放队列中的“听歌设置”。Windows：设置页中的睡眠定时及歌词偏移。
- 支持 15 / 30 / 60 分钟及本曲后停止。期限使用绝对时间；本曲后停止优先于单曲和列表循环。关闭进程后不恢复睡眠任务。
- 歌词偏移范围 ±10 秒，正值提前；Android 悬浮与车载歌词使用相同偏移。
- Web 每 2 秒、Android / Windows 约每 5 秒保存进度，并在部分队列操作或退出时补存。异常退出可能丢失最后一个保存周期内的进度。
- 重启只恢复队列、选中项和位置，首次主动播放再解析地址。播放状态仍是设备本地状态，未实现跨设备实时续播。
- 修复暂停时切换音质、等待地址时暂停、队列删除及清空后迟到响应导致误播的问题。

### 4. 完整歌单副本

- Web：“音乐库 → 导入外链歌单”；公开歌单详情提供“保存为我的歌单”。
- Windows：“设置 → 导入公开歌单”；公开歌单详情提供整单保存按钮。
- Android：保留分享链接导入，并在公开歌单详情提供整单副本保存。
- QQ / 网易链接经官方域名白名单校验，服务端逐跳校验短链接重定向；完整读取后再预览和保存。
- 空、私有、超限、中断或不完整的歌单不生成半张副本。按歌曲平台与 ID 去重，重试相同内容不会重复导入同一副本。

### 5. 下载、本地音乐与账号快照

- Android：“歌曲更多 → 下载到离线音乐”；“我的 → 离线下载”查看进度、取消、删除或播放。DownloadManager 管理传输；同曲下载串行检查，失败或缺失文件可重试。
- 只有系统标记成功且实际文件存在、非空时才优先本地播放。下载权限与音质由服务端实际响应决定；歌词和封面仍可能需要联网。
- Windows：“设置 → 扫描音乐目录 / 打开本地音乐”。扫描子目录并读取标题、歌手、专辑、时长，每次最多 5000 首，跳过目录链接。清空索引保留原文件。
- 本地文件独立于云歌单，列表中的云收藏、加云歌单及下载操作禁用；播放不上传这类歌曲的云历史或请求云歌词。
- 三端元数据按账号隔离，云端失败保留对应账号快照。Web 断网恢复及账号切换迟到响应已做浏览器回归。快照不包含完整音频，Web 未新增可在首次断网访问时启动的完整离线 PWA。

### 6. 专辑、歌手与推荐

- 三端歌曲可进入 QQ / 网易歌手和专辑，合作歌手保留独立 ID。没有可靠 ID 的歌曲不伪造链接。
- 歌手页优先真实作品分页；降级搜索明确显示“搜索到的歌曲”，按歌手名精确匹配，不把姓名搜索伪装为完整作品目录。
- 关注与取消关注保存到账号，最多 100 位，三端可读取。异常旧关注项会被过滤。
- Web 首页、Android 首页 / 我的、Windows 首页提供“为你选歌”。喜欢权重 3、近期播放权重 1，按同平台歌手生成候选，排除已喜欢歌曲并去重；显示“你喜欢 / 你最近听过某歌手”等理由，无偏好时回退新歌。
- 尚未新增专辑收藏、完整歌手专辑目录、场景电台、分类搜索或外部推荐模型。

### 7. 音频能力与边界

- 曲尾 25 秒内，仅对确定的下一首预取一个地址，最多保留一条、45 秒有效；随机、单曲循环、即将睡眠或本曲停止时跳过。失败不打断当前播放，正式切歌仍可重新解析。
- 预取的是 URL，不是整首音频缓存，因此不保证零间隙播放。
- Web 均衡器使用实际 Web Audio 图：60 / 230 / 910 / 3600 / 14000 Hz，±12 dB，带增益余量以降低削波风险。手动开启并保存频段值，音源经同源代理播放。
- 实际音质使用解析结果，用户偏好与真实降级结果分开显示。
- 无缝播放和交叉淡化尚未实现。Android 逐曲装载、Windows 单 MediaPlayer 和 Web 单 audio，需要改成连续队列或双播放器，并验证解码、采样率、缓存和音量衔接。
- Windows EQ 尚未实现：现有管线没有接入可配置滤波图，需要独立音频图或受支持的效果组件及设备回归。本轮没有增加无法影响声音的开关。

## 会员、游客权限与下载额度（2026-11-10）

- 后台新增「会员与权限」，分别配置游客、普通用户和会员的收听开关、收听音质、下载开关、下载音质、每日 / 每月次数及流量额度；留空不限，0 无额度。关闭限制后所有身份放开，管理员始终不限。新站点会员默认全音质，旧站点沿用原下载权限。

- 已知大小先预留流量，未发送部分结束时退回；未知大小逐块扣额，超额中断。处理客户端断开后的结算，失败取址和不可用文件不扣次数。自然日 / 月按北京时间切换，用量重启后保留。

- 用户编辑窗口支持查看和重置下载用量，重置记入审计；前台设置展示额度、会员标识与身份受限音质，游客可按后台授权直接下载。站点设置、缓存和权限分别保存，避免互相覆盖。
