# 会员与权限

管理后台 `/admin/` 的「会员与权限」为游客、普通用户和会员分别配置：

- 收听开关与允许收听的音质。
- 下载开关与允许下载的音质。
- 每日、每月下载次数。
- 每日、每月下载流量，后台单位为 MB。

额度留空为不限，0 为无额度；每日与每月限制同时生效。按北京时间的自然日与自然月计算，月底无需清零历史数据即可切换到新周期。会员可全部放开，也可以单独关闭下载。管理员不受限制。会员身份仍由管理员在「用户管理」中指定，没有增加付款或自动续费。

关闭「会员与权限限制」后，所有身份（包括游客）都可收听、下载全部可用音质，不受次数和流量限制。已保存的角色策略与下载用量保留，重新开启后继续按策略核验。基础接口防刷限流仍然保留。

首次安装默认开放所有身份收听；游客不允许下载，普通用户可下载标准 / 高品质，会员可下载全部音质，次数与流量不限。已有部署首次升级会沿用原下载开关、角色和音质范围，避免自动放宽权限，之后可在后台分别调整。缓存音质与权限独立：服务器可共享保存全部音质，但用户只能取得自己获准的音质。

下载用量也可在「用户管理」的编辑窗口查看，管理员可重置指定用户的额度，操作记入审计日志。前台账号设置显示本人或当前游客的用量，音质菜单禁用当前身份无权收听的音质。

## 服务端核验

`POST /api/url` 将客户端请求音质与服务器角色策略求交集，无法请求任意高音质；命中共享缓存也执行同样检查。播放地址使用加密并认证的短期凭证，绑定身份、音质与有效期，不返回可绕开站点权限的上游直链。`GET /api/stream` 每次取流（包括拖动进度和 HEAD）重新核验当前权限。变更角色会失效原登录会话，旧链接不能用于新身份。

`POST /api/download` 检查当前身份的下载权限、音质和额度后，签发 5 分钟有效的一次性下载凭证。`GET /api/download/file` 再次检查当前权限与额度，并在一个 SQLite 事务内领取凭证、预留下载次数和流量。多端并发请求也不能同时花掉最后一份额度；复制他人的凭证、修改凭证或重复取流会被拒绝。旧版可重复使用的下载签名不再接受。

仅获取下载地址不扣次数。缓存文件存在或上游响应可用后，实际开始下载时计一次；音源解析失败、上游不可用或已知大小超过剩余额度时不扣次数。已知大小先预留流量，传输结束退回未发送部分；未知大小则在每块数据发送前检查和扣除流量，超额会中断传输。已经开始的下载即使中断也计一次，已经发送的流量不退回。下载链接不支持 Range 或重复续传，失败后重新发起下载取得新凭证。

用量持久存于 `data/miyin.db` 的 `download_usage`，重启服务、刷新页面和重新登录都不会重置。下载凭证存于 `download_tickets`；过期凭证和超过 100 天未更新的旧周期记录会清理。站点设置与会员策略的局部保存不会覆盖其他设置。

这些规则保护本站播放和下载接口。允许在线播放的音频仍可能被录制或保存，下载开关不能充当 DRM，也无法撤回用户以前已经下载的本地文件。

## 游客额度与反向代理

游客按服务器识别的网络地址共享额度：IPv4 使用地址，IPv6 使用 /64 网段。更换 User-Agent、清理 Cookie、本地存储、刷新和伪造客户端角色不会获得新额度。同一公网出口的访客共用额度；匿名用户更换真正的公网网络后，无法可靠判断其是否同一个人。需要严格按人核算时应关闭游客下载，使用账号额度。

默认只信任连接本身的来源地址，不接受请求中自行填写的 `X-Forwarded-For` 或 `X-Real-IP`。反向代理部署时，设置 `MIYIN_TRUSTED_PROXIES` 为实际代理的固定 IP 或必要的 CIDR，逗号分隔。服务器从右向左检查转发链，取距离可信代理最近的非可信地址，避免客户端在链首伪造 IP。

例如代理确实运行在本机时，可配置 `MIYIN_TRUSTED_PROXIES=127.0.0.1/32,::1/128`；Docker 中应填写实际代理容器地址，不要信任 `0.0.0.0/0` 或任意客户端所在网段。代理必须正确追加或覆盖转发头，并限制后台服务只能通过预期的代理路径访问。未配置时，代理后的访客会共享代理地址的额度，权限不会被放开。

## 接口与兼容

- `GET /api/config`：包含角色策略、当前访问权限与用量，并保留旧客户端的 `download` 字段。
- `GET /api/access`：当前账号 / 游客的权限与用量。
- `GET/PUT /api/admin/config`：管理员读取、局部更新 `membership`；额度、音质和角色字段在服务端严格校验。
- `GET/DELETE /api/admin/users/:userId/access`：管理员查看或重置指定用户用量。

Web、Android 和 Windows 使用同一后端检查，原生客户端通过已有的播放 / 下载地址字段兼容新凭证；修改客户端参数不会绕过服务端音质、额度或身份核验。升级后旧的播放和下载链接需要重新获取；已下载的本地媒体继续由客户端管理。

验证覆盖权限参数篡改、缓存与音源、角色变更、日 / 月边界、并发扣额、未知大小流量、一次性链接、游客转发头、IPv6 网段、重启持久化和管理员重置。浏览器回归覆盖后台保存、角色切换、权限关闭、移动布局、用户用量及游客下载。
