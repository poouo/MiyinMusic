# Web UI 重构与播放交互修复

## 设计方向

- 产品：为使用不同音乐平台的听众提供统一的搜索、收藏和播放入口。
- 性格：沉静、利落、有一点温度。
- 世界：唱片店的石墨唱片、纸质封套与暖色标签。
- 视觉重点：真实歌单封面与唱片组合；播放页的歌曲封面。
- 识别细节：小唱片中心点和暖橙选择状态，重复用于品牌、首页和播放入口。

用户已确认采用「石墨灰 + 暖橙唱片店」方向。保留原有内容顺序与七套主题的设置标识。

全项目文案原则：界面保持简洁，不常驻展示“点击、拖动、右键”等操作教学。使用简短的按钮名和必要的无障碍标签表达功能，保留输入格式、真实状态和错误反馈。桌面歌词平时只显示歌词；未锁定时悬停显示工具条与半透明底板，锁定时悬停只显示解锁按钮且没有底板。

## 原界面问题

- 全局样式多次叠加主题和播放器补丁，重复规则让布局难以维护。
- 彩色背景、玻璃模糊和渐变同时竞争，封面内容缺少视觉层级。
- 导航、标题、卡片和小型按钮的字号、字重、间距不一致。
- 桌面播放条功能密集，歌词、音量和右侧操作缺少分组。
- 音量入口只有静音按钮，完整播放页也没有音量滑杆。
- 麦克风图标实际用于显示歌词，语义不符；队列与歌词互相替换。
- 随机和循环采用两个独立开关，可组合出难以理解的状态。
- Windows 随机下一首可能抽到当前曲目；三端的手动与自动切歌边界不一致。
- Android 歌手头像未绑定点击，且缺少歌手详情路由与页面。
- 移动列表隐藏部分列后，网格结构和操作按钮仍按桌面布局保留。

## 九轮调整

### 1. 间距

以 4px 为主要间距步长，统一侧栏导航、页面边距和卡片节奏。播放条划分歌曲、播放控制、歌词进度和功能操作四组；音量前增加分隔与留白。

### 2. 颜色

默认深色使用石墨中性色阶，暖橙用于选择和关键操作。浅色使用纸白底色与较深橙色文字；其他主题保留各自强调色，降低背景染色。

### 3. 图标

Web 线性图标统一为 1.5 描边，移除歌词麦克风入口。三端用一个按钮表示顺序、列表循环、单曲循环和随机模式；收起朝左，展开朝右。

### 4. 文案

首页改为「从五个平台，找到你的下一首」。移除未验证的更新频率与登录下载承诺，发现页请求结束但没有内容时提供明确提示。

### 5. 字体

统一系统字体、主次文字和数字样式，降低过重字重；按钮和辅助文字保持可读，快捷键使用键帽表示。

### 6. 布局

首页以搜索与真实精选歌单构成主区域，桌面补充排行榜和歌单广场导航。按屏宽重排播放条、卡片和歌曲列表，完整播放页保持歌词与音量可见。

### 7. 细节

统一边框、圆角、悬停和键盘焦点状态。音量支持点击、拖动与方向键，调整静音中的音量会解除静音；进度和音量方向键不再同时触发全局播放快捷键。

### 8. 视觉

用真实歌单封面与 CSS 唱片构成首页视觉，保留音乐内容自身的颜色。移除全屏播放背景的封面模糊层；没有生成图片，也没有图片生成提示词。

### 9. 动效

保留轻量页面进入、菜单出现和必要加载反馈，移除装饰性缩放和布局尺寸过渡，并尊重减少动态效果的系统偏好。

## 行为修复

- Web 底部播放条与完整播放页共用音量控件，显示百分比并保存设置。
- Web 歌词默认显示，播放队列改为独立弹窗。
- 三端统一循环顺序：顺序 → 列表循环 → 单曲循环 → 随机 → 顺序。
- 单曲循环的自然结束重播本曲，手动下一首仍前进；顺序播放在列表末尾自然停止，手动下一首回到首曲。
- 随机下一首排除当前曲目，上一首优先返回实际播放历史；模式与列表变更会清理历史。
- Android 歌手头像进入实际歌手详情，支持热门歌曲、播放全部、收藏、错误提示及重试。移动 Web 的歌手入口也完成导航检查。

- `npm run typecheck`、`npm run build`：Web 与服务端通过。
- `node --import tsx --test scripts/playback.test.ts`：4 项通过，覆盖模式切换、队尾、单曲循环与随机排除当前曲。
- Windows WinUI 项目 x64 构建通过；`desktop-winui/tests/PlaybackOrder.Tests` 回归检查通过。
- Android `:app:compileDebugKotlin :app:testDebugUnitTest` 通过，共 14 项测试、0 失败。
- 浏览器检查 7 个主要路由 × 7 个屏宽（360、390、768、900、1024、1280、1440px），无页面横向溢出或播放条分组重叠；7 套主题均能切换。
- 浏览器验证音量实际写入音频元素、静音恢复、进度键盘操作、四模式切换、顺序播放末尾停止、独立队列、收起展开与手机歌手导航，无未捕获脚本错误。
- 最终截图检查覆盖桌面深色、桌面浅色、移动首页和移动完整播放页。

浏览器播放回归使用本地静音 WAV 和固定歌词，其他发现与歌手数据来自本地服务实际接口。音源供应方的真实音频播放、Android 和 Windows 真机交互尚未进行人工验收。

## 播放布局与交互续作（2026-11-10）

- Windows 底栏改为左侧封面与歌曲信息、中间播放控制和进度、右侧音质/桌面歌词/队列。鼠标离开窗口 5 秒后，歌曲信息原位置显示当前歌词，返回立即恢复。
- Windows 音量入口改为向上弹出的竖向调节浮窗，含百分比和独立静音按钮；音量为零时取消静音可恢复此前音量，调整结果保存。
- Web / Windows 底部播放条空白处可展开完整播放页；按钮、进度条等交互区域不会误触展开。Windows 使用淡入与轻微上移动画。
- Web / Windows 完整播放页改为左侧封面、右侧歌曲信息及受限高度的歌词，缩小歌词占比；Windows 共用底栏控制，不再重复展示一套按钮。
- 播放中，完整播放页鼠标离开窗口约 8 秒后淡出控制区域，返回立即恢复，暂停时保持显示；Web 仅对支持悬停的设备启用。Windows 标题栏内容也随之淡出，系统窗口按钮保留。
- Web / Windows 播放模式改为四项菜单：随机播放、顺序播放、单曲循环、列表循环；当前项勾选，选择任一项会清除旧的随机历史及冲突状态。Web 支持方向键、首尾键和 Escape，修正手机菜单越界。
- Web 桌面布局与 Windows 左侧导航可收起为图标栏，并保存状态。歌单、创建歌单与账号入口继续可用。
- Windows 桌面歌词右侧边缘支持调宽，右下角支持同时调宽与字号；锁定时禁用缩放，宽度和字号自动保存，重置位置时恢复默认宽度。
- 验证：Web 生产构建通过；播放模式 5 项单元测试通过；Windows 纯逻辑回归覆盖 8 秒边界/移回重置、锁定命中、缩放限制与音质/播放顺序；Windows Debug 编译零警告零错误，自包含 x64 Release 发布成功。
- Web 本地模拟接口与静音 WAV 回归 6 组场景通过：导航持久化、四模式菜单、空白处展开和控件隔离、8 秒隐藏/移回恢复、暂停不隐藏、390px 手机歌词空间/菜单边界，未捕获异常为零。
- 已查看 Windows 实际启动窗口和底栏布局；当前桌面自动化的点击/键盘输入未产生可靠响应，因此原生悬停、拖动、音量浮窗与真实音频交互仍需人工验收。没有部署线上服务。
